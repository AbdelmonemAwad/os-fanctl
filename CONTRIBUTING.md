# Working on this

A plugin that gives a repurposed appliance its fan curve back, and every temperature it can read.

It is one part of the [os-xgs-npu](https://github.com/AbdelmonemAwad/os-xgs-npu) project, and works the same way.

## House rules

- **Pull requests, never a direct push to `main`**, and the checks green before a merge.
- **English** in code and documentation; Arabic belongs in the translation files only.
- **Claim only what has been run.** A page says what was measured and on which appliance, and
  says plainly what was not. "Should work" is not a state this project records.
- **Withdraw a wrong claim in the change that disproves it**: struck through, with the correction
  after it, so the reasoning that led to it stays readable.
- **Every string on a page has its Arabic.** The plugin keeps its own translation; the
  checks refuse a page string without one.
